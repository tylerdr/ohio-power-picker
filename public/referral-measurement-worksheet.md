# Can you measure completed analyses from a referral page?

Use this worksheet to decide whether you have a baseline before investing in an embedded electricity comparison. Use aggregate totals from one territory and one referral page. Keep the completed worksheet in your own records.

## Define what to count

| Item | Your scope |
| --- | --- |
| Utility territory and referral page | |
| Decision this baseline will inform | |
| First and last inquiry dates | |
| Last date to count delivery to those inquiries | |
| How the source of each inquiry is established | |
| Who can confirm the aggregate counts | |
| A. Unique qualifying inquiries attributed to that page in the inquiry period | |
| B. Inquiries from A with an analysis delivered by the cutoff | |

Count each inquiry once. Exclude unrelated calls, automatic enrollments and analyses delivered to inquiries outside the cohort. If either count is missing, the source cannot be confirmed, or A is zero, record the baseline as unavailable. If B exceeds A, reconcile the counts first. Otherwise divide B by A.

## Worked example with fictional counts

An example page produced 20 attributable qualifying inquiries during October. Five of those inquiries received analyses by November 15. The baseline is 5 ÷ 20 = 25%. Eight additional inquiries with unknown sources stay outside both counts. The result describes completion among the 20 attributed inquiries. It gives no completion rate for the eight inquiries with unknown sources.

## Record the decision

- **Baseline unavailable** — agree how to capture the referral source and confirm delivery before evaluating an embedded comparison.
- **Baseline available** — record the rate and cohort size. Agree what improvement and delivery cost would justify a small comparison test. Use the same definitions and allow the same time for delivery when comparing cohorts.
